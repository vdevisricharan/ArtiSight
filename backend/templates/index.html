Photo-Critique API

This service lets you upload a photo, receive a detailed critique via Gemini 2.5, get AI-driven improvement tips, and pull curated learning resources.

Endpoints

  • POST /upload  -  upload an image file and receive a critique
  • POST /suggest  -  turn the critique into bullet-point improvements
  • POST /resources  -  get Google search resources based on the critique + suggestions

Quick test

Run curl -F "file=@/path/to/photo.jpg" http://localhost:5000/upload

Full OpenAPI / Swagger docs are also served at /apidocs.
